# AUREA DENTAL — публикация

## 1. GitHub
1. Создай новый репозиторий, например `aurea-dental`.
2. Загрузи в него все файлы проекта.
3. НЕ загружай `.env.local` и секретные ключи.

## 2. Vercel
1. Открой Vercel и войди через GitHub.
2. Add New → Project.
3. Выбери репозиторий `aurea-dental`.
4. Framework Preset: Next.js.
5. Build Command: `next build`.
6. Нажми Deploy.

## 3. Форма
До подключения реального endpoint форма работает в demo-режиме.

После создания endpoint:
- Vercel → Project → Settings → Environment Variables
- Name: `NEXT_PUBLIC_FORM_ENDPOINT`
- Value: URL endpoint
- включи Production + Preview, если нужно
- Save → Redeploy

После этого отправь тестовую заявку с компьютера и телефона.

## 4. Домен
В Vercel: Project → Settings → Domains → Add.

Vercel покажет точные DNS-записи. Добавляй именно их у регистратора домена. Не меняй DNS-записи наугад.

После обновления DNS проверь:
- HTTPS работает;
- `www` и основной домен ведут туда, куда нужно;
- сайт открывается без предупреждений;
- форма отправляет заявку.

## 5. Перед передачей клиенту
Проверь:
- desktop;
- mobile;
- меню и якоря;
- все CTA;
- форму;
- изображения;
- favicon;
- title/description;
- отсутствие горизонтального скролла;
- скорость;
- 404;
- домен + HTTPS.

## 6. Реальные данные клиента
Перед публикацией заменить демонстрационные:
- адрес;
- телефон;
- email;
- расписание;
- лицензии и юридические данные;
- медицинские заявления и гарантии;
- отзывы и статистику, если они не подтверждены клиентом.
