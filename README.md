# AUREA DENTAL — Client Ready

Премиальный одностраничный сайт на Next.js 14.

## Запуск

```bash
npm install
npm run dev
```

Открой `http://localhost:3000`.

## Production

Перед публикацией замени демонстрационный домен `aurea-dental.example` в:
- `app/layout.js`
- `app/robots.js`
- `app/sitemap.js`

на настоящий домен клиента.

### Форма заявки

Сайт поддерживает внешний endpoint формы через переменную окружения:

```env
NEXT_PUBLIC_FORM_ENDPOINT=https://...
```

Если переменная не задана, форма работает в demo-режиме и показывает подтверждение локально. Для реального клиента подключи Formspree, Web3Forms, свой API или CRM endpoint и укажи его URL в `.env.local` / настройках Vercel.

## Деплой на Vercel

1. Загрузить проект в GitHub.
2. Импортировать репозиторий в Vercel.
3. Указать production domain.
4. Добавить `NEXT_PUBLIC_FORM_ENDPOINT` в Environment Variables, если форма должна отправлять заявки.
5. Сделать Deploy.
6. Проверить desktop + mobile, все якоря, форму, HTTPS и домен.

## Важно

- Не добавляй секретные API-ключи в `NEXT_PUBLIC_*`.
- После подключения реальной формы протестируй отправку с телефона и компьютера.
- Контент, адрес, телефон, лицензии, реквизиты и медицинские заявления должны быть заменены на реальные данные клиента до публикации.
